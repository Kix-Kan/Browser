# Release notes

## 0.1.0 — Development

- Selected Firefox ESR 140.12.0 as the initial engine foundation.
- Added original KixKan branding overlay and local-first start/new-tab extension.
- Added privacy-focused enterprise policies and preference defaults.
- Added verified source retrieval, Debian packaging, experimental Flatpak manifest, and release signing workflow.
- Added independent upstream security monitoring and validation tests.

This development release has not yet produced a boot-tested or signed browser binary.
