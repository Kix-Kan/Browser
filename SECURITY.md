# Security policy

Supported versions will be listed after the first signed release. Until then, `0.1.0` is development-only and must not be used as a production browser.

Report suspected vulnerabilities through GitHub's private vulnerability reporting for `Kix-Kan/KixKan-Browser`. Do not include exploits, private browsing data, crash dumps, or customer information in a public issue.

KixKan Browser tracks Mozilla ESR advisories independently from KixKan OS. Critical and actively exploited fixes take precedence over normal feature work.
